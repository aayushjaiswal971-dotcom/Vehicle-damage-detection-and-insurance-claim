Welcome! This is a complete full-stack web application for automated 
vehicle damage assessment using deep learning.

═══════════════════════════════════════════════════════════════════════
                          QUICK START GUIDE
═══════════════════════════════════════════════════════════════════════

STEP 1: Install Python 3.8 or higher
        Download from: https://www.python.org/downloads/

STEP 2: Open Command Prompt in this directory

STEP 3: Install dependencies
        Command: pip install -r requirements.txt
        Time: ~5-10 minutes

STEP 4: Run setup
        Command: python setup.py
        Time: ~1 minute

STEP 5: Train models
        Command: python train_models.py
        Time: ~2 minutes

STEP 6: Start application
        Command: python app.py
        OR
        Double-click: run.bat

STEP 7: Open browser
        URL: http://localhost:5000

STEP 8: Register and start analyzing vehicle damage!

═══════════════════════════════════════════════════════════════════════
                          WHAT THIS SYSTEM DOES
═══════════════════════════════════════════════════════════════════════

✓ User Authentication
  - Register with email and password
  - Secure login system
  - Personal dashboard

✓ Damage Detection
  - Upload vehicle images
  - AI detects damaged parts (bumper, door, hood, etc.)
  - Identifies damage location and extent

✓ Severity Classification
  - Minor: < 5% damage
  - Moderate: 5-15% damage
  - Severe: > 15% damage

✓ Cost Estimation
  - Automatic repair cost calculation
  - Range: ₹5,000 to ₹100,000+
  - Based on damage severity and part type

✓ History Tracking
  - All assessments saved to database
  - View past damage reports
  - Track damage over time

═══════════════════════════════════════════════════════════════════════
                          TECHNOLOGY STACK
═══════════════════════════════════════════════════════════════════════

Backend:
  • Flask (Web Framework)
  • SQLite (Database)
  • PyTorch (Deep Learning)
  • YOLOv8 (Object Detection)
  • Mask R-CNN (Segmentation)
  • LightGBM (Severity Classification)
  • XGBoost (Cost Estimation)
  • OpenCV (Image Processing)

Frontend:
  • HTML5, CSS3, JavaScript
  • Responsive Design
  • Modern UI
